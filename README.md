## Selected work

**[ArXivist](https://github.com/qosi-org/arxivist)** — Multi-agent pipeline that converts a paper into a reproducible Git repo. Six stages: parse the paper, build a Scientific Intermediate Representation, plan the architecture, generate code, generate a notebook, compare results against the paper's claims. Packaged as a Claude Skill.

**[NBA-AI](https://github.com/saiompatro/NBA-AI)** — Real-time NBA analytics dashboard. Flask and Socket.IO, ingesting live play-by-play, running an XGBoost shot-quality model and a PyTorch win-probability model. The shot-quality model trains on synthetic data and I say so in the README, because there is no real-shot ground truth to backtest against.

**[tennis-match-predictor](https://github.com/saiompatro/tennis-match-predictor)** — ATP and WTA predictions from Elo, workload, serve-return data, and point-by-point simulation.

**[GOAL-AI](https://github.com/saiompatro/GOAL-AI)** — World Cup predictor and player analysis tool.
